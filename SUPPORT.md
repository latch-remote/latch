# Getting help

- **Something does not work.** Look at the troubleshooting sections of
  [docs/MACOS.md](docs/MACOS.md) and [docs/WINDOWS.md](docs/WINDOWS.md)
  first. If it is still broken, open a
  [bug report](https://github.com/latch-remote/latch/issues/new/choose); the
  form asks for the things that are always needed (versions, the path
  Tailscale took, the stats overlay's numbers).
- **A question, an idea, or a setup you want to show.**
  [Discussions](https://github.com/latch-remote/latch/discussions).
- **A security problem.** Privately, as [SECURITY.md](SECURITY.md) says.

Latch is a volunteer project. There is no support contract and no
guaranteed response time.

Development issues and discussions require access to the private source
repository. Include versions, operating systems, the toolbar's route and
stats, and steps to reproduce when contacting a maintainer. Public releases
and corresponding source snapshots are available without a GitHub login.
[Releases](https://github.com/latch-remote/latch-releases/releases) ·
[Maintainer contact](https://github.com/MrBeldum)
