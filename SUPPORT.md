# Getting help

- **Something does not work.** Look at the troubleshooting sections of
  [docs/MACOS.md](docs/MACOS.md) and [docs/WINDOWS.md](docs/WINDOWS.md)
  first. If it is still broken, open a
  [bug report](https://github.com/MrBeldum/latch/issues/new/choose); the
  form asks for the things that are always needed (versions, the path
  Tailscale took, the stats overlay's numbers).
- **A question, an idea, or a setup you want to show.**
  [Discussions](https://github.com/MrBeldum/latch/discussions).
- **A security problem.** Privately, as [SECURITY.md](SECURITY.md) says.

Latch is a volunteer project. There is no support contract and no
guaranteed response time.
